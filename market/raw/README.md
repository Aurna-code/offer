# market/raw

This folder is optional.

Use it only if you want to add more competitor notes beyond `inputs/market-evidence.md`.

Recommended format for each file:

- listing title
- why it is relevant
- price tiers
- delivery times
- revision policy
- buyer inputs
- promised deliverables
- scope risks
- one lesson for Repo Onboarding Snapshot

Do not paste giant raw pages here unless you really need them.
Condensed notes are more useful than scrapbook dumps.
