# Repo Onboarding Snapshot — Codex kit

This kit gives Codex enough structure to turn the offer into:
- an Upwork Project Catalog listing
- ACP job schemas and examples
- a sample report
- launch and red-team checklists

## Suggested workflow
1. Open this folder as a Codex project.
2. Run `prompts/00-kickoff-plan.md`
3. Run prompts 01 through 07 in order
4. Or use `prompts/08-one-shot-run.md` if you want one larger pass

## Why this kit exists
The offer should not be positioned as a generic code audit.
The market evidence here suggests the right wedge is:
clarity for inherited or unfamiliar repositories.

## Files you should edit manually
- `inputs/offer-brief.md` if you change the product promise
- `inputs/market-evidence.md` if you gather better comparator data later

## Files Codex should create
Everything under `outputs/`
