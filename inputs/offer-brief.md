# Offer
Repo Onboarding Snapshot

# Core Promise
In 48 to 72 hours, turn one unfamiliar repository into a usable onboarding report and first-week action plan.

# Buyer situation
The buyer has inherited, paused, or newly joined a repository and cannot quickly determine where to read, run, or modify first.

# Deliverables
- repo summary
- architecture highlights
- likely entry points
- startup / reading path
- missing context checklist
- key risks
- first 7 priority tasks
- confidence note

# Exclusions
- implementation
- debugging sessions
- calls
- formal security review
- formal performance audit

# Tone
Senior, calm, exact, technical, useful.

# Delivery targets
Starter: 2 days
Standard: 3 days
Advanced: 4 days

# Revision policy
1 revision for factual corrections or narrow scope adjustments only.
