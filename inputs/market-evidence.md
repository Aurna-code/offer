# Market evidence for Repo Onboarding Snapshot

Use this file as the primary market evidence input for positioning and pricing.
Do not assume the market is empty. Treat these as the closest substitutes and boundary cases for the offer.

## Comparator A — Direct closest match
Title: Decision-Grade Repository Audit | 48-Hour Technical Due Diligence Report
Surface: Upwork Project Catalog
Type: Direct comparator
Why it matters:
- one repository
- 48-hour turnaround
- written technical assessment
- sold as decision support rather than implementation
Observed signals:
- pricing ladder: $250 / $500 / $950
- delivery times: 2 / 3 / 5 days
- revisions: 0 / 1 / 0
- optional add-ons include a live debrief and a remediation roadmap
- language emphasizes technical due diligence, technical debt clarity, and an orientation for decision-makers
Implications:
- confirms strong demand for narrow repository audits
- supports a faster-turnaround product
- shows that live debrief should be an add-on at most, not the core offer
Risk if copied too closely:
- can drift into investor diligence / CTO-for-hire territory
- can sound too grand or too AWS-specific for a general onboarding product

## Exclusions for this product
Do NOT benchmark against:
- consultations
- bug-fix or feature-build projects
- full modernization / migration retainers
- security audits sold as formal assessments
- low-price architecture reviews that look under-scoped or low-trust

## Core positioning lessons
1. The strongest wedge is not “better code review.” It is “clarity for inherited or unfamiliar repositories.”
2. The offer should feel narrower than a full technical audit and more concrete than a consultation.
3. A fixed, written deliverable with a task-count anchor beats abstract promises.
4. Fast turnaround is a feature, but only if scope is narrow and intake is strict.
5. Avoid bundling implementation, live walkthroughs, or broad security/performance claims into the base package.

## Pricing guidance
- do not price below the level that makes the offer look trivial
- keep the starter tier low enough to be impulse-buyable but not “cheap checklist” territory
- the closest market references suggest that a direct-report product can live above $100 without issue
- use the broad audit offers as anchors, not as a mandate to match their scope
